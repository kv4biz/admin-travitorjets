Admin Platform – Admin Dashboard (staff & manager)
Purpose: Define all pages, actions, and content structure for the admin dashboard (subdomain). No SEO required; all pages are behind login and have noindex. Content, labels, and messages will come from admin-content.ts.

Admin Dashboard Pages (each on its own route):
Common for Staff & Manager:
Admin Overview – stats: open requests, recent activity, pending payments.

Requests Management – table of all requests (filter by type, status, assigned staff). Click to view request detail (chat, invoices, documents).

Request Detail (admin view) – same chat as user but with admin controls: assign/unassign, send invoice, confirm payment, generate final document, close request.

Empty Legs Management – list of all empty legs (admin + PEXJET). CRUD for admin-created. For PEXJET: view only, maybe disable editing.

Create/Edit empty leg: form with aircraft type, route (airport search), dates, price (or on request), destination image/description, is_public toggle.

Aircraft Types Management – CRUD for aircraft models (name, ICAO, class, specs, images). Used in public catalogue and for empty legs/listings.

Aircraft Listings (Acquisition) – CRUD for aircraft for sale/lease (title, description, aircraft type, price, images, status).

Invoices – list of all invoices, filter by request/staff. Click to view details and confirm payment.

Payments – list of payments (pending/confirmed). Staff can confirm a payment (mark as paid).

Documents – all documents uploaded by users and generated by admin. Can view/delete.

Staff Management (manager only) – list staff, invite new staff, revoke invitations, remove staff.

Analytics (manager only) – charts: requests handled per staff, average response time, total revenue.

Data Export (manager only) – export tables (CSV): users, requests, payments, empty legs, aircraft listings.

Admin Profile – update own details, change password.

Admin actions:
Staff:

Pick up open requests (assign to self).

Chat with users.

Send invoices (set amount, bank details, generate reference code).

Confirm payments after checking receipt.

Fill and send final confirmation document (structured JSON → PDF).

Close requests.

CRUD empty legs, aircraft types, aircraft listings.

Manager (additional):

Invite/remove staff.

Reassign any request to any staff.

View all analytics and export data.

Access all staff actions without restriction.

Admin‑only pages (no public access):
All routes under admin.traviatorjets.com/\* are protected by middleware that checks role in profiles.

InviteAcceptForm.tsx
Reads token from URL query param.

Shows form: password, confirmPassword.

On submit: calls acceptInvitation(token, password).

This function:

Validates invitation token in invitations table.
Creates a new user in Supabase Auth using supabase.auth.admin.createUser({ email, password, email_confirm: true }) (requires service role key – we need a secure API endpoint or Edge Function to avoid exposing service key on client).
Updates the profiles role to 'staff'.
Marks invitation as used.
Because this requires service role, we will create a Next.js API route (e.g., /api/accept-invite) that the form calls. That API route uses SUPABASE_SERVICE_ROLE_KEY (server‑side only).

4. API Route for Invitation Acceptance
   app/api/accept-invite/route.ts
   ts
   import { createClient } from '@supabase/supabase-js'
   import { NextResponse } from 'next/server'

export async function POST(request: Request) {
const { token, password } = await request.json()
const supabaseAdmin = createClient(process.env.NEXT_PUBLIC_SUPABASE_URL!, process.env.SUPABASE_SERVICE_ROLE_KEY!)
// 1. Fetch invitation
const { data: invite, error } = await supabaseAdmin.from('invitations').select('_').eq('token', token).single()
if (error || !invite || invite.used_at || new Date(invite.expires_at) < new Date()) {
return NextResponse.json({ error: 'Invalid or expired invitation' }, { status: 400 })
}
// 2. Create user
const { data: authUser, error: createError } = await supabaseAdmin.auth.admin.createUser({
email: invite.email,
password,
email_confirm: true,
})
if (createError) return NextResponse.json({ error: createError.message }, { status: 400 })
// 3. Update profile role
await supabaseAdmin.from('profiles').update({ role: 'staff' }).eq('id', authUser.user.id)
// 4. Mark invitation used
await supabaseAdmin.from('invitations').update({ used_at: new Date().toISOString() }).eq('id', invite.id)
return NextResponse.json({ success: true })
}
